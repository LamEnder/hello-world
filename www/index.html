How games loop their music

  
    
    
  • Intro + loop body. Most game tracks play an opening once. When they reach a loop end, they jump back to a loop start partway through, so the music runs as long as you stay in the area. This page uses the same model.
    • 
    
  • RPG Maker reads LOOPSTART and LOOPLENGTH tags (in samples) from Ogg files. Open a tagged file here and its loop is picked up automatically. Copy the tags above to tag your own files.
    • 
    
  • Rips have a tail. Soundtrack rips are often exported as "two loops, then a fade." So the loop end is usually not the end of the file. The grey tail is the part a game never reaches.
    • 
    
  • Engines. FMOD and Wwise mark loop regions on the track timeline. In Unity, developers often split a track into an intro clip and a loop clip, then schedule the loop to start exactly when the intro ends.
    • 
    
  • Old consoles (NES, SNES era) played sequenced music note by note. Their "loop" was a jump command in the sequence, so there was no audio seam at all.
